# 看店勢 DianInsight

> 讓每天的營運數字，開始說人話。

**DianInsight（看店勢）** 是為多門市、多區域營運管理場景打造的業績管理與 AI 分析平台。它將每日業績、區域表現、門市排名、AI 分析與營運通知整合在同一個管理視角，讓主管更快掌握真正值得注意的變化。

🌐 Preview：<https://preview.dianinsight.com>

## 主要功能特色

### 📊 營運總覽

將營收、交易筆數、來客數、平均客單等核心指標集中呈現，搭配趨勢與門市排名，快速掌握每日營運狀況。

### 📁 業績資料匯入

支援將既有 Excel / CSV 業績資料匯入系統，由系統進行解析、整理與後續分析，降低每天重新製作管理報表的人工成本。

### ✦ AI 營運分析

由系統負責計算真實數據，AI 負責理解與表達，從整體、區域與門市表現中整理出管理者可以直接閱讀的營運重點，包括：

- 整體趨勢與期間比較
- 區域表現差異
- 門市異常與值得注意的變化
- 管理者關注重點

### 🏪 多區域、多門市管理

從公司整體一路查看到區域與個別門市，讓不同管理層依自己的管理範圍取得真正需要的資訊。

### 👥 角色與權限

依管理角色區分資料存取範圍，包括管理員、區域主管與店主管，避免所有使用者都看到與自己無關的營運資料。

### 🔔 營運通知與自動報告

重要營運資訊不必等主管主動登入尋找。系統可將營運摘要、異常提醒與報告透過通知流程送達指定管理者，並支援 Email 報告。

### 🔐 Security by Design

安全不只停留在登入頁。DianInsight 的安全架構涵蓋帳號存取、登入事件、工作階段、安全通知與 **Security Log**，讓重要安全事件能被記錄與查詢。

### 🌏 中英文介面

支援繁體中文與英文介面，並讓報表與 AI 分析依使用者語系呈現。

## 從資料到決策

```text
業績資料匯入
      ↓
系統整理與計算
      ↓
AI 營運分析
      ↓
依角色查看
      ↓
通知 / Email 報告送達
```

DianInsight 的目標不是再增加一張報表，而是把原本散落在 Excel、人工整理、訊息與 Email 之間的營運流程，逐步整合成一套管理者真正能使用的營運系統。
